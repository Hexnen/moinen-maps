# LETR lettering engine: bundled fonts

All fonts below are unmodified files under the SIL Open Font License 1.1 (OFL.txt next to each file). The engine reads their outlines
at runtime and may build missing Polish capitals from a font's own outlines in memory; no modified font file is saved or shipped.
Downloaded 2026-11-13 from the google/fonts GitHub repository (raw.githubusercontent.com/google/fonts/main/ofl/<folder>/), or copied
from invincible-plus-ultra's fonts/ofl (Anton, Bangers, Patrick Hand, which came from the same repository).
